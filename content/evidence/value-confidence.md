# Value Confidence

Every value record carries an amount **and** an evidence state.

1. **Assumed** — asserted, no analysis yet
2. **Modelled** — calculated from assumptions
3. **Observed** — seen in a limited context
4. **Evidenced** — supported by robust evidence
5. **Realised** — banked in operational or financial reality

`£4.2m potential value — Modelled` must never appear equivalent to `£4.2m realised value — Evidenced`.

## What this means for us

Potential value is never included in realised-value totals. Portfolio totals are always reported by state, never as one figure.

## Anti-patterns

- a single "benefits" number on a leadership slide
- upgrading a value state because a deadline is approaching

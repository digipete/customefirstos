# Transformation Economics

We instrument the economics of transformation itself, not only the economics of the services we change.

## Investment

People cost, technology cost, supplier cost, experiment cost, partner effort and other cost.

## Value

Cashable savings, avoided cost, productivity, user benefit, risk reduction and service improvement.

Not all value is financial. Financial and non-financial value must remain distinguishable and must never be summed into a single headline number.

## Good looks like

- cost attributed to the mission that incurred it
- value expressed with an evidence state
- cost per unit of learning treated as a real measure

## Anti-patterns

- benefits arithmetic that mixes modelled and realised value
- investment tracked only at programme level

# Benefits Hypothesis template

Copy this template into your mission folder, or use it directly in GitHub. It is designed to be usable outside the application.

## Fields

- **Benefit description**
- **Type: cashable / avoided cost / productivity / user benefit / risk reduction / service improvement**
- **Amount and unit**
- **Evidence state: assumed / modelled / observed / evidenced / realised**
- **How the state will be upgraded**
- **Owner and review date**

## Notes

Keep the completed benefits hypothesis in Markdown so it stays readable, reviewable and portable.

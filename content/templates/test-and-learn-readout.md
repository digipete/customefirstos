# Test & Learn Readout template

Copy this template into your mission folder, or use it directly in GitHub. It is designed to be usable outside the application.

## Fields

- **Hypothesis tested**
- **What we did and what it cost**
- **What we observed**
- **Evidence strength**
- **Result: supported / partially supported / disproved / inconclusive**
- **Recommendation**
- **What we will not do as a result**

## Notes

Keep the completed test & learn readout in Markdown so it stays readable, reviewable and portable.

# Retrospective template

Copy this template into your mission folder, or use it directly in GitHub. It is designed to be usable outside the application.

## Fields

- **What did we learn about the customer?**
- **What did we learn about ourselves?**
- **What slowed us down?**
- **What evidence changed our minds?**
- **What should become a pattern?**
- **What OS guidance should change?**

## Notes

Keep the completed retrospective in Markdown so it stays readable, reviewable and portable.
